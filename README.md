🎮 Hangman Game

📌 Project Description

Hangman is a simple word-guessing game developed using Python. The player must guess a hidden word one letter at a time. The player wins by guessing all the letters correctly before running out of attempts.

🎯 Objective

To develop a fun and interactive word-guessing game using basic Python programming concepts.

🛠️ Technologies Used

- Python 3
- VS Code

✨ Features

- Random word selection
- Letter-by-letter guessing
- Limited incorrect attempts
- Displays correctly guessed letters
- Shows win or lose messages

▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python hangman.py

If that command does not work, try:

python3 hangman.py

🎮 How to Play

1. Run the Python program.
2. View the hidden word represented by blanks.
3. Enter one letter at a time.
4. Guess the word before your attempts run out.
5. You win if you guess the complete word correctly!
