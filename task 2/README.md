📈 CodeAlpha Stock Tracker

📌 Project Overview
The Stock Tracker is a Python-based project developed as part of Task 2. It allows users to track stock investments, calculate investment values based on stock prices, and view a portfolio summary.

✨ Features
Enter stock symbols and share quantities.
Calculate the investment value for each stock.
Calculate the total investment amount.
Display a stock portfolio summary.
Save portfolio results to a text file (portfolio.txt).
Handle invalid numerical inputs.

🛠️ Technologies Used
Programming Language: Python
Code Editor: Visual Studio Code
Output File: Text file (portfolio.txt)

📂 Project Structure
Task 2/
├── stock\_tracker.py
├── README.md
└── portfolio.txt

Note: portfolio.txt is generated when the program saves the portfolio.
▶️ How to Run the Project
Install Python 3 on your computer.
Open the Task 2 folder in Visual Studio Code.
Open the terminal.
Run the following command:
python stock\_tracker.py

Enter the requested stock symbols and share quantities.
View the portfolio summary in the terminal.
💻 Sample Output
===== Portfolio Summary =====
AAPL: 5 shares = $950.00

Total Investment: $950.00

Portfolio saved to portfolio.txt

Note: This is an illustrative example. Actual output depends on the stock prices and quantities configured in your code.
